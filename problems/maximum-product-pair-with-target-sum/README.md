# Maximum Product Pair With Target Sum

- Difficulty: easy
- Link: https://leetcode.com/problems/maximum-product-pair-with-target-sum/
- Contest: Q1, номер задачи на момент решения ещё не опубликован

## Statement

You are given an integer array `nums` and an integer `target`.

A pair of **distinct** indices `(i, j)` is **valid** if:

- `nums[i] + nums[j] == target`
- `nums[i] > nums[j]`

Return a **valid** pair `[i, j]` whose **product** `nums[i] * nums[j]` is **maximum** among all valid pairs. If no valid
pair exists, return `[-1, -1]`.

If multiple valid pairs achieve the **maximum** product, you may return **any** of them.

**Example 1:**

**Input:** nums = [1,2,3,4], target = 5

**Output:** [2,1]

**Example 2:**

**Input:** nums = [-3,-1,4,2], target = 1

**Output:** [3,1]

**Example 3:**

**Input:** nums = [3,3,5], target = 6

**Output:** [-1,-1]

**Constraints:**

- `2 <= nums.length <= 100`
- `-100 <= nums[i], target <= 100`

## Idea

Это Two Sum: у элемента `a` партнёр определён однозначно, `b = target − a`. Значит, пар
не больше `n`, и перебирать их парами за O(n²) незачем. Достаточно знать, есть ли в массиве
значение `b`. Значения лежат в `[-100, 100]`, поэтому вместо хеш-таблицы хватает массива
из 201 ячейки «значение → какой-нибудь индекс».

Условие `nums[i] > nums[j]` даёт сразу три вещи. Пара упорядочена, поэтому каждая
неупорядоченная пара встречается при проходе один раз, как `(большее, меньшее)`. Индексы
различны сами собой: при `a > b` это разные значения. А равные значения (`3 + 3` из
примера 3) отсекаются, хотя индексы у них разные.

Выбор лучшей пары проясняет тождество
`a·b = ((a + b)² − (a − b)²) / 4 = (target² − (a − b)²) / 4`.
Сумма у всех пар одна, поэтому произведение зависит только от разности: чем ближе
`a` и `b` к `target/2`, тем оно больше. В примере 2 пара `(2, −1)` с разностью 3
обходит `(4, −3)` с разностью 7, хотя обе отрицательны. В коде максимум ищется
прямым сравнением произведений, тождество лишь объясняет, почему при равенстве разностей
годится любая пара: произведения у таких пар тоже равны.

Граница таблицы: `b = target − a` может выйти за 100 (например, `target = 100, a = −50`).
Но тогда `b > 100 ≥ a`, и проверка `b >= a` отсекает пару раньше обращения к таблице.
Снизу выход за −100 возможен и проверяется явно.

Ответ неоднозначен, поэтому тест сверяет не индексы, а их свойства: пара допустима, а
её произведение равно максимуму из перебора всех пар. Перебор гоняется на 20 000
случайных входах с узким диапазоном, где совпадений и равных значений много.

- Time: O(n)
- Space: O(1): таблица фиксированного размера, 201 ячейка
