# Longest Resilient Subarray II

- Difficulty: medium
- Link: https://leetcode.com/problems/longest-resilient-subarray-ii/
- Contest: Q3, номер задачи на момент решения ещё не опубликован

## Statement

You are given an integer array `nums` and an integer `k`.

A subarray is **resilient** if, for **every** position in it, deleting the element at that position leaves the
**remaining** elements with a **sum divisible** by `k`.

For a subarray of length 1, the remaining sum is 0, which is divisible by `k`.

Return the length of the **longest resilient subarray**.

A **subarray** is a contiguous **non-empty** sequence of elements within an array.

**Example 1:**

**Input:** nums = [2,4,6,3], k = 2

**Output:** 3

**Example 2:**

**Input:** nums = [1,4,7,1], k = 3

**Output:** 4

**Example 3:**

**Input:** nums = [5,5,4,8], k = 4

**Output:** 2

**Constraints:**

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= 10^5`

## Idea

Пусть `S` — сумма подмассива длины `L`. Условие «для **каждой** позиции `S − a ≡ 0`»
переписывается как `a ≡ S (mod k)` для каждого элемента. Значит, все элементы дают
**один и тот же остаток** `r`. Тогда `S ≡ L·r`, и условие превращается в одно сравнение
на длину:

`(L − 1)·r ≡ 0 (mod k)`.

Обратное тоже верно: если остатки равны и сравнение выполнено, то `S − a ≡ L·r − r ≡ 0`
для любого элемента. Получился критерий: подмассив устойчив тогда и только тогда, когда
он лежит внутри серии одного остатка и его длина удовлетворяет сравнению.

Решения сравнения `r·x ≡ 0 (mod k)` — это ровно кратные `k / gcd(r, k)`. Это частный
случай теоремы о линейных сравнениях при `b = 0` и `x₀ = 0`: решения идут с шагом
`n/d` (CLRS, 3rd ed., Theorem 31.24, с. 948 (PDF 969)). Значит, допустимы длины
`L = 1 + t·step`, где `step = k / gcd(r, k)`. Длина 1 допустима всегда (`t = 0`), и это
совпадает с оговоркой в условии. При `r = 0` шаг равен 1, и годится вся серия.

Условие на длину не зависит от того, где подмассив стоит внутри серии. Поэтому в каждой
максимальной серии длины `m` лучший ответ — `1 + ⌊(m − 1)/step⌋·step`. Остаётся пройти
массив, нарезать его на серии с равным остатком и взять максимум.

Пример 3 показывает, почему одного равенства остатков мало. `[5, 5]` — серия остатка 1
при `k = 4`, шаг 4, поэтому длина 2 недопустима. А `[4, 8]` с остатком 0 подходит
целиком.

Отличие от [части I](../longest-resilient-subarray-i/README.md) только в ограничении:
`n ≤ 10^5` вместо 2500. Перебор подмассивов с префиксными суммами — это O(n²) ≈ 10^10
операций, и он уже не проходит. Критерий же даёт один проход, и решение переносится
из части I без изменений. Переполнения нет: сумм в решении нет вовсе, только остатки.

Тест сверяет решение с перебором по определению: каждый подмассив, каждое удаление. Во
входе два случайных остатка, чтобы серии были длинными, а `gcd(r, k)` бывал больше 1.
Мутант, у которого шаг всегда равен `k`, эталон ловит сразу: `nums=[12 16] k=4`.

- Time: O(n log k): проход по массиву и НОД на каждую серию, серий до n
- Space: O(1)
